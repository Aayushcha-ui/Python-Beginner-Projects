# Employee Payroll System

This is a simple Employee Payroll System made with Python.

I created this project to practice working with employee data and file handling.

1. Features

- Add Employee
- Calculate Salary
- Generate Payslip
- Search Employee
- Save Payroll Data
- Exit

2. Concepts Used

- Functions
- Dictionary
- If-else
- While loop
- File handling
- User input

3. How to Run

Run the Python file:

python payroll.py

4. What I Learned

This project helped me understand how to store employee information and save the data into a file.
