# Expense Tracker

This is a simple Expense Tracker made using Python.

I made this project to practice storing and working with income and expense records.

1. Features

- Record Income
- Record Expense
- Categorize Transaction
- Generate Monthly Summary
- Search Records
- Save Records
- Exit

2. Concepts Used

- Functions
- Dictionary
- If-else
- While loop
- File handling
- User input

3. How to Run

Run the Python file:

python expense_tracker.py

4. What I Learned

While making this project, I practiced working with dictionaries, functions and saving data into a file.
