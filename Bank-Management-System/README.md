# Bank Management System

This is a simple Bank Management System made using Python.

I made this project to practice Python basics and understand how functions and dictionaries can be used to manage data.

1. Features

- Create Account
- Deposit Money
- Withdraw Money
- Check Balance
- Exit

2. Concepts Used

- Python functions
- Dictionary
- If-else
- While loop
- User input

3. How to Run

Run the Python file:

python bank.py

4. What I Learned

While making this project, I learned how to store account information in a dictionary and perform different operations using functions.
