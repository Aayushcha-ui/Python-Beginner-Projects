# Hospital Patient Record System

This is a simple Hospital Patient Record System made using Python.

I created this project to practice managing records using Python.

1. Features

- Register Patient
- Search Patient
- Update Patient
- Delete Patient
- Save Records
- Exit

2. Concepts Used

- Functions
- Dictionary
- If-else
- While loop
- File handling
- User input

3. How to Run

Run the Python file:

python hospital.py

4. What I Learned

This project helped me understand how to add, search, update and delete records using a dictionary.
